# SkillRack Automation — AI Instructions

You have access to a SkillRack automation toolbox in this directory. This file tells you how to use it to solve Python programming problems on SkillRack.

## Architecture

- `skillrack.py` — CLI entry point. Use `--list`, `-r` (read), `<PID> <file>` (submit).
- `solutions.py` — `get(pid)` returns a code string for known PIDs.
- `captcha.py` — OCR solver for the CAPTCHA.
- `nav.py`, `run.py`, `qread.py`, `editor.py` — lower-level modules.
- `solver.py` — high-level solve loop.

## Setup Requirement

Chrome/Brave must be running with `--remote-debugging-port=9222` and the user must be logged into SkillRack.

```bash
pip install -r requirements.txt && playwright install chromium
```

## Two Problem Types

| Type | URL pattern | Run button | Description |
|------|-------------|------------|-------------|
| Course | `tutorprogram.xhtml` | `j_id_a3` | Fill-in-the-blanks. Server has a hidden template with `____` markers. Your paste replaces the `____`. |
| Easy Challenge | `codeprogram.xhtml` | `j_id_bg` | Full code from scratch. |

## CAPTCHA (Critical)

The CAPTCHA is always `X+Y=?` where X and Y are 1-3 digit numbers.

**DO NOT use `tessedit_char_whitelist`** — it corrupts digit `9` (reads `07+6` instead of `97+6`). Use plain `--psm 6 --oem 3`.

Image pipeline: `convert('L')` → `autocontrast(cutoff=2)` → 4x `LANCZOS` resize → double `SHARPEN` → `invert`. The expression is on the second line of the OCR result; parse with `\d+` regex.

The CAPTCHA solve + Proceed click MUST happen in a single Playwright session. If you disconnect between filling the captcha and clicking Proceed, the session key expires.

## Fill-in-the-Blanks Rule

When the editor contains a template, the server replaced `____` with the editor content. Your paste should contain ONLY the code that replaces `____`. Do NOT include lines that are already in the template. Examples:
- Template: `if num%5 == 0:\n____` → paste `        pass`
- Template: `while True:\n    n=int(input())\n    ____` → paste `    if num%9 == 0:\n        break`

## Code Pasting (always use this)

```js
const ed = window.ace.edit(document.querySelector('.ace_editor').id);
ed.getSession().setValue(code);
const ta = document.getElementById('txtCode');
if (ta) { ta.value = code; ta.dispatchEvent(new Event('change', {bubbles: true})); }
```

## Running Code

```js
PrimeFaces.ab({s:"j_id_bg", f:"code", p:"txtCode,langs,customtcpanel,j_id_bg", u:"progresspanel,srmsg"});
```

Change `j_id_bg` to `j_id_a3` for course problems. The button ID is the Run button's PrimeFaces ID — always find it first from the page if unsure.

## Navigation — Easy Challenges

Starting from `trackshome.xhtml`:

1. Level 1 View → `lev1.xhtml`
2. Click "View" for "Learn C, Java, Python, SQL..." → `codeprogramgroup.xhtml?gt=CODETUTOR`
3. Click Python "Show" (`pkglistform:cttbl:2:j_id_41`)
4. Click "50 EASY CHALLENGES" "Show" (`pkglistform:j_id_49:3:j_id_4h`)
5. Click "View" on target part (`cttbl:N:j_id_4u`)
6. Click "Solve" on target problem (`pctbl:N:j_id_5w`)
7. CAPTCHA appears → solve → Proceed → editor loads → paste → Run

## Navigation — Course Problems

Starting from `tutorprogram.xhtml?gt=CODETRACK`:
1. Find course chapter in the list
2. Click chapter → problem list appears
3. Click problem → CAPTCHA → Proceed → editor loads → paste → Run

## Proceed Next Behavior

After clicking "Proceed Next" on an Easy Challenge, you return to the part's problem list. You must click "Solve" again for the next problem — it does NOT advance directly.

## Failure Handling

1. **Compile/runtime error**: Your code is wrong. Read the problem again, fix input/output format, resubmit.
2. **Wrong answer**: Edge cases (negative numbers, float input, multi-line input). Fix and resubmit.
3. **CAPTCHA fails after 3 attempts**: Reload the page to get a fresh CAPTCHA.
4. **Page state corruption**: Navigate back to the track home and re-navigate fresh.
