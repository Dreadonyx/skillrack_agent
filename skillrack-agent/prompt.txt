# SkillRack Automation Agent - Instructions for AI

## Overview
You are an AI agent that autonomously solves SkillRack programming problems.
You have a tool `skillrack.py` that handles browser automation (connect, navigate,
CAPTCHA, paste, run, detect results). You use it as a component in your loop.

## Architecture
- **skillrack.py** — your "hands": clicks, types, reads results (Python + Playwright)
- **You (AI)** — your "brain": reads problems, writes code, iterates on failure

## Before Starting
- Chrome/Brave must be running with `--remote-debugging-port=9222`
- User must be logged into SkillRack in that browser
- Run `pip install -r requirements.txt && playwright install chromium`

## Workflow

### Step 1: List available problems
```
python skillrack.py --list -m <module>
```
Modules: codetrack, codetutor, dailychallenge, dailytest, codetest

### Step 2: Read a problem
```
python skillrack.py <PID> -r -m <module>
```
This returns the problem title + description + examples.

### Step 3: Write solution → save to .c/.py/.java file
Write code based on the problem description and examples.
- C solutions: use `pidXXX.c` naming
- Python3 solutions: use `pidXXX.py` naming
- Always match the expected input/output format from examples

### Step 4: Submit and run
```
python skillrack.py <PID> solution.c -m <module> -l C
python skillrack.py <PID> solution.py -m <module> -l PYTHON3
```
The tool handles: navigation, CAPTCHA solving, language selection,
code pasting (via Ace editor API), clicking Run, and result detection.

### Step 5: Iterate on failure
If result shows failed tests → debug code → resubmit.

## CAPTCHA Details (IMPORTANT)
The CAPTCHA is ALWAYS a simple addition: `N+N` where N is 1-3 digits.
Answer is always ≤ 3 digits, typically 1-2 digits.

The CAPTCHA image contains TWO lines:
1. User ID (e.g. `113224032018`)
2. The math expression (e.g. `9+8`)

The tool handles OCR by:
- Getting the base64 image data directly from `#j_id_75` element
- Preprocessing: autocontrast → 4x upscale → sharpen → invert
- OCR with tesseract PSM 6, whitelist `0123456789+*`
- Taking the LAST OCR line (strips the user ID line)
- Extracting short (≤3 digit) numbers around `+`

If the tool reports CAPTCHA failed after 3 attempts, the OCR
might have misread. You can manually compute by looking at the
raw OCR output in the logs.

## Navigation Timings
Wait for each step:
| Action | Wait time |
|--------|-----------|
| Page load after navigation | 2-3 seconds |
| After clicking "Show" (expand section) | 2 seconds |
| After clicking "View" (expand part) | 2 seconds |
| After clicking "Solve" | 4 seconds |
| After clicking "Proceed" | 1.5 seconds |
| After CAPTCHA filled + Proceed clicked | 3 seconds |
| After setting language | 0.5 seconds |
| After pasting code | 1 second |
| After clicking "Run" | 6+ seconds (up to 15 for results) |

## Error Recovery
1. **Navigation fails**: If the editor doesn't load, try navigating
   to the module page first, then re-navigate. Some pages need a
   fresh load because PrimeFaces session gets stale.

2. **CAPTCHA fails after 3 retries**: Refresh the page (the CAPTCHA
   changes on reload), then try again. The tool handles 3 retries
   automatically.

3. **Run fails with compile/runtime error**: The code is wrong.
   Read the problem again, check input/output format, fix the code,
   save, and resubmit.

4. **Run succeeds with failed tests**: Read the problem carefully,
   check edge cases (empty input, single element, max constraints,
   negative numbers, etc.), fix the code, resubmit.

5. **Page state corruption**: If clicks aren't working, the PrimeFaces
   UI may be in a bad state. Navigate back to the module home page
   and re-navigate to the problem fresh.

## Module-Specific Navigation

### CodeTutor (50 Easy/Very-Easy/Average Challenges)
```
URL: https://skillrack.com/faces/candidate/codeprogramgroup.xhtml?gt=CODETUTOR
Steps:
  1. Load page → wait 2s
  2. Click Python "Show" button (id: pkglistform:cttbl:2:j_id_41) → wait 2s
  3. Click "50 EASY CHALLENGES" "Show" button (id: pkglistform:j_id_49:3:j_id_4h) → wait 2s
  4. Click "View" on each part until the target PID appears (id: cttbl:N:j_id_4u) → wait 2s
  5. Click "Solve" on the target PID → wait 4s
  6. CAPTCHA appears → solve → click "Proceed" → wait 3s
  7. Editor loads
```

```
URL: https://skillrack.com/faces/candidate/codeprogram.xhtml?pid=<PID>

the Solve button with matching PID in its parent context.
```

## Code Pasting (Critical)
SkillRack has a 30-character diff protection (`cs()` function).
To bypass this, ALWAYS use the Ace editor's API directly:
```js
// This is what skillrack.py does internally:
const editor = window.ace.edit('ctracktxtCode');
editor.getSession().setValue(code);
const ta = document.getElementById('txtCode');
if (ta) ta.value = code;
if (ta) ta.dispatchEvent(new Event('change', { bubbles: true }));
```
