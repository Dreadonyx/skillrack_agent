# SkillRack Automation — AI Instructions

You have access to a SkillRack automation toolbox in this directory. This file tells you how to use it to solve programming problems on SkillRack (Python and C courses).

## Architecture

- `skillrack.py` — CLI entry point. Use `--list`, `-r` (read), `<PID> <file>` (submit).
- `solutions.py` — `get(pid)` returns a code string for known PIDs.
- `captcha.py` — OCR solver for the CAPTCHA.
- `nav.py`, `run.py`, `qread.py`, `editor.py` — lower-level modules.
- `solver.py` — high-level solve loop.
- `course_solver.py` — course-specific fill-in-blank solver.

## Setup

Chrome/Brave must be running with `--remote-debugging-port=9222` and logged into SkillRack.

```bash
pip install -r requirements.txt && playwright install chromium
```

## CAPTCHA (Critical)

Always `X+Y=?`. Use `--psm 6 --oem 3` (no whitelist — corrupts digit `9`). Image pipeline: grayscale → autocontrast → 4x resize → sharpen → invert. The expression is on the second OCR line; parse with `\d+`. Fill + click Proceed in ONE Playwright session or the session key expires.

## Fill-in-the-Blanks Rule

Paste ONLY the code replacing `____`. Do NOT include lines already in the template. The platform merges your paste with the server-side template.

## Code Pasting

```js
const ed = window.ace.edit(document.querySelector('.ace_editor').id);
ed.getSession().setValue(code);
const ta = document.getElementById('txtCode');
if (ta) { ta.value = code; ta.dispatchEvent(new Event('change', {bubbles: true})); }
```

## Run Button

Submit the form via the Run button's PrimeFaces ID (find from page if unsure).

## Navigation

Starting from `trackshome.xhtml` → Level 1 → CODETUTOR → language → course → chapter → problem.

## C Course Specifics

- Templates use global `struct Node *lhead=NULL, *ltail=NULL;`
- SLL: `struct Node { int price; struct Node *next; }`
- DLL: adds `*prev`
- CDLL: circular (last→next = head, head→prev = last)
- Position is always 1-indexed
- Output: `20->34->16->NULL` (SLL) / `20 <=> 34 <=> NULL` (DLL/CDLL)
- For fill-in-blanks, `int index;` may need explicit declaration if template uses `for(index=0;...)` undeclared

## Failure Handling

1. **Compile/runtime error**: Fix code (check input/output format, includes, function signatures).
2. **Wrong answer**: Check edge cases (negatives, zero, single element, bounds).
3. **CAPTCHA fails after 3 attempts**: Reload page for fresh CAPTCHA.
4. **Page state corruption**: Navigate back to track home and re-navigate fresh.
